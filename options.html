本地改造 想使用其他人工智能模型？ 编辑并复制一段可安全交给编程助手的提示词 可交给编程助手

你可以直接编辑提示词。复制前完成以下三步：

  1. 在编程助手中打开 YouTube Digest 解压后的项目文件夹。
  2. 把 [PROVIDER] 和 [MODEL] 替换成你想使用的服务和模型。
  3. 不要在提示词或聊天中加入 API 密钥。代码准备好后，请自行填写。
